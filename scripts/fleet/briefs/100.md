# #100 付方档案的四个全局唯一键：保持全局，把假设写成明文 + 换成可读错误

议题正文即 spec（`gh issue view 100 --comments`）。**口径已经拍了，不要再论证键该不该改。**

## 决定

**一家公司只能是一个租户，不会出现同一家公司开多个租户的情况**（业务方原话）。所以：

- **四个全局键全部保留，一个都不改**（`uk_payer_no` / `uk_partner_payer_id` / `uk_credit_code` / `uk_tax_no`）。**不要写迁移脚本、不要动 schema。**
- 这四个键里有三个是构造上全局唯一的（`payerNo` = `P<milis><6位随机数>`、`partnerPayerId` = `PAYER_<UUID>`），只有 `credit_code` / `tax_no` 会真的挡住人——挡的是「同一个统一社会信用代码出现第二个租户」，而那正是**它该挡的**（付方就是开票主体；ADR 0005 已经写了「每个回收企业是独立租户」「一家回收企业一个子商户档案」）。

**现在的问题不是键错了，而是它没写下来、而且撞上时只抛裸 `DuplicateKeyException`（500）。**

## 要做的

1. **把这条假设写成明文。** 现在它是**没写下来的**——这是这张票存在的原因。位置你定，但仓库有先例：ADR 0024 末尾补过「边界说明，指向本 ADR」，所以**在 ADR 0005 末尾补一段**是自然的（它已经说了「每家回收企业是独立租户」与「一家回收企业一个子商户档案」，把「因此付方档案的信用代码 / 税号全局唯一，一家公司不可能有两个付方」这句接上去即可）。顺带看一眼 `CONTEXT.md` 有没有「付方档案」这个术语条目——有就在那里也点一句，没有就别新造词。
2. **把 500 换成可读错误。** `PayerInfoServiceImpl` 的 create / update 之前加一道**跨租户**预检（`TenantUtils.executeIgnore`，租户插件会挡住跨租户查询），命中就抛新错误码。
   - **文案不许点名是哪一家企业**（不要回租户名 / 租户编号）——那会变成跨租户信息泄露，而 `#91` 的评审专门为「别把别家的存在漏出去」把跨租户作废链接做成了「当作不存在」。这块的措辞同理：只说「该统一社会信用代码已被另一家企业登记为付方」，要处理就找平台运营。
   - **DB 的键保留作兜底**（并发下预检与插入之间有窗口）——这是仓库既有的模式（服务层预检 + 唯一键兜底，参考 `NaturalPersonServiceImpl.register` 捕 `DuplicateKeyException` 的那一段）。
   - 值本身要不要 trim / 大小写归一？`credit_code` 是 18 位大写字母数字，想清楚再写，别让「同一个税号的大小写差异」绕过预检又不撞键。
3. **收掉 `#99` 留下的整表排除。** `IcbcUniqueKeySchemaParityTest` 里的 `KEY_DECISION_PENDING = {icbc_payer_info}` 是「等这张票决定」的**自清理排除项**，现在决定下来了。而测试建表**只建了 `credit_code` / `tax_no`，没建 `payer_no` / `partner_payer_id`** —— 这是货真价实的差异。
   - 把 `icbc_payer_info` 从排除集合里移掉，并把**测试建表对齐到生产**（补那两个全局键）。
   - 对齐之后如果有测试数据撞键（同 `#99` 处理过的那类），**改测试数据成真实形状，不许把 schema 改松回去**。
4. **测试**：
   - 跨租户：租户 1 已有付方（信用代码 X），租户 2 再建同一个 X → **可读错误**（不是 500），且**错误文案里不含租户名 / 编号**。要真开租户拦截器（照 `IcbcTenantTestConfiguration`），不然「跨租户」这层根本没被执行。
   - 同租户内重复 → 也拒。
   - 比对测试在**不带排除项**的情况下跑绿。
5. 全量测试绿（`@@TEST_CMD@@`，一条 reactor，**不要 `mvn install`**）。

## 报告

逐条对账 + common.md 那五面透镜的答案，外加：
- **文案为什么不点名**：写清你的判断与依据（跨租户透明度 vs 泄露存在性）；
- 预检与 DB 键各自管什么（哪一层防并发）；
- `## 文档` 改了哪个 ADR 的哪一段，以及为什么放那里；
- 确认你没有改任何 schema 的键（本票**不该**有迁移文件）。
