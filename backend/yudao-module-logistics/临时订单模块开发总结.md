# 临时订单模块开发总结

## 概述

根据数据库表 `logistics_temporary_order` 的结构，按照 ruoyi-vue-pro 规范创建了完整的临时订单管理功能模块。

## 数据库表结构

表名：`logistics_temporary_order`

主要字段：
- `id`: 主键ID
- `order_no`: 订单编号（唯一）
- `task_id`: 关联的运输任务ID
- `driver_id/driver_name`: 司机信息
- `waste_type/waste_name`: 废料类型和名称
- `estimated_quantity/quantity_unit`: 预计数量和单位
- `pickup_location/pickup_latitude/pickup_longitude`: 取货位置信息
- `pickup_time`: 取货时间
- `producer_*`: 产废方信息（姓名、电话、身份证号）
- `discovery_photos`: 发现现场照片URLs（JSON格式）
- `estimated_value`: 预估价值
- `payment_*`: 支付相关信息（状态、金额、时间、方式、凭证）
- `converted_to_formal`: 是否已转为正式订单
- `formal_order_id/conversion_time`: 转换信息
- `remark`: 备注
- `tenant_id`: 租户ID

## 业务场景

临时订单表用于记录司机在运输过程中发现的临时废料收集需求：

1. **发现场景**：司机在执行运输任务时，发现路线上有临时的废料需要收集
2. **快速记录**：司机可以快速创建临时订单，记录废料信息和产废方信息
3. **支付管理**：支持现场支付或后续支付，记录支付凭证
4. **转换流程**：临时订单可以转换为正式订单，纳入正规流程管理
5. **状态跟踪**：完整的状态流转（未支付→已支付→已退款/已取消）

## 创建的代码文件

### 1. 枚举类

#### TemporaryOrderPaymentStatusEnum.java
临时订单支付状态枚举，包含以下状态：
- UNPAID(0, "未支付")
- PAID(1, "已支付")
- REFUNDED(2, "已退款")
- CANCELLED(3, "已取消")

### 2. 数据对象 (DO)

#### TemporaryOrderDO.java
与数据库表一一对应的数据对象，包含所有数据库字段，继承自 `BaseDO`。

### 3. 数据访问层 (Mapper)

#### TemporaryOrderMapper.java
数据访问接口，继承自 `BaseMapperX`，提供以下查询方法：
- `selectPage()`: 分页查询
- `selectList()`: 列表查询
- `selectByOrderNo()`: 根据订单编号查询
- `selectByTaskId()`: 根据任务ID查询
- `selectByDriverId()`: 根据司机ID查询
- `selectByPaymentStatus()`: 根据支付状态查询
- `selectByConvertedToFormal()`: 根据转换状态查询
- `selectByWasteType()`: 根据废料类型查询
- `selectCountByTaskId()`: 统计任务订单数
- `selectCountByDriverId()`: 统计司机订单数

### 4. VO 类

#### TemporaryOrderCreateReqVO.java
创建请求对象，包含完整的校验注解：
- 订单编号唯一性校验
- 手机号格式校验
- 身份证号格式校验
- 经纬度范围校验
- 数值精度校验

#### TemporaryOrderUpdateReqVO.java
更新请求对象，继承创建VO并添加id字段。

#### TemporaryOrderPageReqVO.java
分页查询请求对象，继承自 `PageParam`，包含各种查询条件。

#### TemporaryOrderRespVO.java
响应对象，包含所有字段和支付状态名称等扩展字段。

#### TemporaryOrderExcelVO.java
Excel 导出对象，使用 `@ExcelProperty` 注解标注各字段。

### 5. 转换器 (Convert)

#### TemporaryOrderConvert.java
使用 MapStruct 实现的对象转换器，提供以下转换方法：
- DO 与 VO 之间的转换
- 支付状态值转支付状态名称
- 列表和分页结果的转换

### 6. 业务逻辑层 (Service)

#### TemporaryOrderService.java
业务逻辑接口，定义了临时订单管理功能：

**基础CRUD方法：**

- `getTemporaryOrder()`: 获取临时订单
- `getTemporaryOrderDetail()`: 获取临时订单详情
- `getTemporaryOrderPage()`: 分页查询临时订单

**查询方法：**
- `getTemporaryOrderByOrderNo()`: 根据订单编号查询
- `getTemporaryOrderListByTaskId()`: 根据任务ID查询
- `getTemporaryOrderListByDriverId()`: 根据司机ID查询
- `getTemporaryOrderListByPaymentStatus()`: 根据支付状态查询
- `getTemporaryOrderListByConvertedToFormal()`: 根据转换状态查询
- `getTemporaryOrderListByWasteType()`: 根据废料类型查询

**业务方法：**
- `payTemporaryOrder()`: 支付临时订单
- `refundTemporaryOrder()`: 退款临时订单
- `cancelTemporaryOrder()`: 取消临时订单
- `convertToFormalOrder()`: 转为正式订单

#### TemporaryOrderServiceImpl.java
业务逻辑实现类，实现了所有接口方法，包含：
- 完整的CRUD逻辑实现

### 8. 错误码扩展

在ErrorCodeConstants.java中添加了8个临时订单相关错误码：
- TEMPORARY_ORDER_NOT_EXISTS: 临时订单不存在
- TEMPORARY_ORDER_ORDER_NO_DUPLICATE: 订单编号已存在
- TEMPORARY_ORDER_CANNOT_DELETE_CONVERTED: 已转为正式订单的临时订单无法删除
- TEMPORARY_ORDER_CANNOT_DELETE_PAID: 已支付的临时订单无法删除
- TEMPORARY_ORDER_PAYMENT_STATUS_NOT_UNPAID: 订单状态不是未支付，无法支付
- TEMPORARY_ORDER_PAYMENT_STATUS_NOT_PAID: 订单状态不是已支付，无法退款
- TEMPORARY_ORDER_CANNOT_CANCEL_CONVERTED: 已转为正式订单的临时订单无法取消
- TEMPORARY_ORDER_ALREADY_CONVERTED: 临时订单已转为正式订单

## 使用说明

### 1. 权限配置
需要在系统中配置以下权限：
- `logistics:temporary-order:query`: 查询权限
- `logistics:temporary-order:create`: 创建权限
- `logistics:temporary-order:update`: 更新权限
- `logistics:temporary-order:delete`: 删除权限
- `logistics:temporary-order:export`: 导出权限
- `logistics:temporary-order:pay`: 支付权限
- `logistics:temporary-order:refund`: 退款权限
- `logistics:temporary-order:cancel`: 取消权限
- `logistics:temporary-order:convert`: 转换权限

### 2. 业务流程示例

```java
// 1. 司机发现临时废料，创建临时订单
TemporaryOrderCreateReqVO createReqVO = new TemporaryOrderCreateReqVO();
createReqVO.setOrderNo("TO202401010001");
createReqVO.setTaskId(taskId);
createReqVO.setDriverId(driverId);
createReqVO.setDriverName("张三");
createReqVO.setWasteType("HW01");
createReqVO.setWasteName("废机油");
// ... 设置其他字段
Long orderId = temporaryOrderService.createTemporaryOrder(createReqVO);

// 2. 现场支付
temporaryOrderService.payTemporaryOrder(orderId, 
    new BigDecimal("800.00"), "现金支付", null);

// 3. 转为正式订单
temporaryOrderService.convertToFormalOrder(orderId, formalOrderId);
```

### 3. 查询使用示例

```java
// 查询司机的所有临时订单
List<TemporaryOrderDO> driverOrders = temporaryOrderService
    .getTemporaryOrderListByDriverId(driverId);

// 查询未支付的临时订单
List<TemporaryOrderDO> unpaidOrders = temporaryOrderService
    .getTemporaryOrderListByPaymentStatus(
        TemporaryOrderPaymentStatusEnum.UNPAID.getStatus());

// 查询未转换的临时订单
List<TemporaryOrderDO> unconvertedOrders = temporaryOrderService
    .getTemporaryOrderListByConvertedToFormal(false);
```
