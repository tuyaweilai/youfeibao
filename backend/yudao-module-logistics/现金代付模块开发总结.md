# 现金代付模块开发总结

## 概述

根据数据库表 `logistics_cash_advance` 的结构，按照 ruoyi-vue-pro 规范创建了完整的现金代付记录管理功能模块。

## 数据库表结构

表名：`logistics_cash_advance`

主要字段：
- `id`: 主键ID
- `task_id`: 关联的运输任务ID
- `order_id`: 关联的订单ID
- `driver_id/driver_name`: 司机信息
- `payment_amount`: 支付金额
- `payment_time`: 支付时间
- `payment_location`: 支付地点
- `payment_method`: 支付方式（默认CASH）
- `payee_name/payee_phone`: 收款人信息
- `payment_photos`: 支付现场照片URLs（JSON格式）
- `receipt_photos`: 收据照片URLs（JSON格式）
- `notify_status/notify_time`: 通知状态和时间
- `reconcile_status/reconcile_time`: 对账状态和时间
- `reconcile_remark`: 对账备注
- `reconcile_operator_id/reconcile_operator_name`: 对账操作员信息
- `remark`: 备注
- `tenant_id`: 租户ID

## 业务场景

现金代付表用于记录司机在运输过程中的现金代付情况：

1. **代付场景**：司机在运输过程中需要代付费用（如过路费、装卸费等）
2. **记录管理**：详细记录代付金额、时间、地点、收款人等信息
3. **凭证管理**：支持上传支付现场照片和收据照片作为凭证
4. **通知流程**：支持通知相关人员代付情况
5. **对账管理**：支持财务人员进行对账操作，确保资金安全

## 创建的代码文件

### 1. 枚举类

#### CashAdvanceNotifyStatusEnum.java
现金代付通知状态枚举，包含以下状态：
- NOT_NOTIFIED(0, "未通知")
- NOTIFIED(1, "已通知")
- NOTIFY_FAILED(2, "通知失败")

#### CashAdvanceReconcileStatusEnum.java
现金代付对账状态枚举，包含以下状态：
- NOT_RECONCILED(0, "未对账")
- RECONCILED(1, "已对账")
- RECONCILE_FAILED(2, "对账失败")

### 2. 数据对象 (DO)

#### CashAdvanceDO.java

- `selectPage()`: 分页查询

- `selectByDriverId()`: 根据司机ID查询

- `selectByReconcileStatus()`: 根据对账状态查询
- `selectByPaymentMethod()`: 根据支付方式查询

#### CashAdvanceCreateReqVO.java

- 字段长度校验
- 数值精度校验

#### CashAdvanceUpdateReqVO.java
更新请求对象，继承创建VO并添加id字段。

#### CashAdvancePageReqVO.java
分页查询请求对象，继承自 `PageParam`，包含各种查询条件。

### 8. 错误码扩展

在ErrorCodeConstants.java中添加了4个现金代付相关错误码：
- CASH_ADVANCE_NOT_EXISTS: 现金代付记录不存在
- CASH_ADVANCE_CANNOT_DELETE_RECONCILED: 已对账的现金代付记录无法删除
- CASH_ADVANCE_NOTIFY_STATUS_NOT_NOT_NOTIFIED: 记录状态不是未通知，无法通知
- CASH_ADVANCE_RECONCILE_STATUS_NOT_NOT_RECONCILED: 记录状态不是未对账，无法对账

## 使用说明

### 1. 权限配置
需要在系统中配置以下权限：
- `logistics:cash-advance:query`: 查询权限
- `logistics:cash-advance:create`: 创建权限
- `logistics:cash-advance:update`: 更新权限
- `logistics:cash-advance:delete`: 删除权限
- `logistics:cash-advance:export`: 导出权限
- `logistics:cash-advance:notify`: 通知权限
- `logistics:cash-advance:reconcile`: 对账权限

### 2. 业务流程示例

```java
// 1. 司机代付费用，创建代付记录
CashAdvanceCreateReqVO createReqVO = new CashAdvanceCreateReqVO();
createReqVO.setTaskId(taskId);
createReqVO.setOrderId(orderId);
createReqVO.setDriverId(driverId);
createReqVO.setDriverName("张三");
createReqVO.setPaymentAmount(new BigDecimal("100.00"));
createReqVO.setPaymentTime(LocalDateTime.now());
createReqVO.setPaymentMethod("CASH");
createReqVO.setPayeeName("收费站");
// ... 设置其他字段
Long recordId = cashAdvanceService.createCashAdvance(createReqVO);

// 2. 通知相关人员
cashAdvanceService.notifyCashAdvance(recordId);

// 3. 财务对账
cashAdvanceService.reconcileCashAdvance(recordId, 
    "对账完成", operatorId, "财务人员");
```

### 3. 查询使用示例

```java
// 查询司机的所有代付记录
List<CashAdvanceDO> driverRecords = cashAdvanceService
    .getCashAdvanceListByDriverId(driverId);

// 查询未对账的代付记录
List<CashAdvanceDO> unReconciledRecords = cashAdvanceService
    .getCashAdvanceListByReconcileStatus(
        CashAdvanceReconcileStatusEnum.NOT_RECONCILED.getStatus());

// 查询任务的代付记录
List<CashAdvanceDO> taskRecords = cashAdvanceService
    .getCashAdvanceListByTaskId(taskId);
```
