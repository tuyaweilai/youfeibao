## 1. 功能说明

聚富通开票付方支付接口：

商户发起向自然人支付货款时，调用该接口生成企业支付页面。

**请求方式：** POST

| --- | --- |

## 3. 通用请求参数

| 参数名 | 类型 | 是否必输 | 最大长度 | 描述 | 示例值 |
| --- | --- | --- | --- | --- | --- |
| app_id | str | true | 20 | APP编号，APP的编号，应用在API开放平台注册时生成 | 10000000000000261019 |
| msg_id | str | true | 40 | 消息通讯唯一编号，每次调用独立生成，APP级唯一 | urcnl24ciutr9 |
| format | str | false | 5 | 请求参数格式，仅支持json | json |
| charset | str | false | 10 | 字符集，缺省为UTF-8 | UTF-8 |
| encrypt_type | str | false | 5 | 加密类型，现在仅支持AES，部分接口支持加密，如接口无需加密，参数中此字段无需上送 | AES |
| sign_type | str | false | 5 | 签名类型，CA-工行颁发的证书认证，RSA-RSAWithSha1，RSA2-RSAWithSha256，缺省为RSA | RSA2 |
| sign | str | true | 300 | 报文签名 | ERITJKEIJKJHKKKHJEREEEEEE |
| timestamp | str | true | 20 | 交易发生时间戳，yyyy-MM-dd HH:mm:ss格式 | 2016-10-29 20:44:38 |
| ca | str | false | 2048 | ca认证，采用ca认证方式时，需上送证书 | FSGFRHRGHTHTFDFER |
| biz_content | str | true | - | 请求参数的集合 | - |

### 7.3 特别注意事项

当返回-500041、-500042或其他未知异常时，切勿重复提交！请使用指令提交接口对应的查询接口查询指令的最新状态后再做处理。
