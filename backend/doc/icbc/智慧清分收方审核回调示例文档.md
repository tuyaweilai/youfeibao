## 1. 基础智慧清分、产权招投标、再生资源（数据接口）

### 1.1 收方新增数据接口 (/jft/api/user/edpreceive/add/V1)

#### 1.1.1 报文格式

```json
{ 
  "appId": "", 
  "appIdSub": "", 
  "outUserId": "", 
  "result": ""
}
```

#### 1.1.2 接收变量名

`biz_content`

#### 1.1.3 报文内容

| key | 长度定义 | 说明 |
| --- | --- | --- |
| biz_content | 无限制 | 通知消息，json 格式 |

#### 1.1.4 biz_content 数据定义

| 变量名称 | 变量命名 | 变量类型 | 说明 |
| --- | --- | --- | --- |
| 平台外部编号 | appId | String | 一定返回，申请入参参数 |
| 付方编号 | appIdSub | String | 一定返回，申请入参参数（产权/招投标场景不返回） |
| 外部用户编号 | outUserId | String | 一定返回，申请入参参数 |
| 收方审核结果 | result | String | 一定返回，审核通过为 pass，审核拒绝为 reject |

#### 1.1.5 具体示例（仅供参考）

```json
{
  "appId": "10000000000000123456",  // 平台外部编号
  "appIdSub": "20230101987",        // 付方编号
  "outUserId": "20230202123456",    // 外部用户编号
  "result": "pass"                  // 审核结果
}
```

## 2. 再生资源（页面接口）

### 2.1 收方新增页面接口 (/jft/ui/user/edpopenacct/submit/V1)

```json
{ 
  "appId": "", 
  "appIdSub": "", 
  "outUserId": "", 
  "result": "", 
  "receiverAccount": "", 
  "openacctStatus": "", 
  "mediumId": "", 
  "mobileNo": ""
}
```

#### 2.1.2 接收变量名

`biz_content`

#### 2.1.3 报文内容

| key | 长度定义 | 说明 |
| --- | --- | --- |
| biz_content | 无限制 | 通知消息，json 格式 |

#### 2.1.4 biz_content 数据定义

| 变量名称 | 变量命名 | 变量类型 | 说明 |
| --- | --- | --- | --- |
| 平台外部编号 | appId | String | 一定返回，申请入参参数 |

| 外部用户编号 | outUserId | String | 一定返回，申请入参参数 |
| 收方审核结果 | result | String | 一定返回，审核通过为 pass，审核拒绝为 reject |
| 收方入驻账号 | receiverAccount | String | 页面接口返回（使用 utf-8 base64 转码加密） |
| 开户状态 | openacctStatus | String | 页面接口返回，字典值：00-初始，01-开户中，02-开户成功，03-开户失败 |
| 电子账户账号 | mediumId | String | 页面接口开户成功时返回（使用utf-8 base64 转码加密） |
| 收方手机号 | mobileNo | String | 页面接口返回（使用 utf-8 base64 转码加密） |

