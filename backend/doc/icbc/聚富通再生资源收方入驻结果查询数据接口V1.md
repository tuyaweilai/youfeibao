## 1. 功能说明

本接口为数据接口。合作方通过该接口查询用户收方入驻结果信息。

**请求方式：** POST

## 2. 请求路径

| 环境 | 地址 |
| --- | --- |
| 正式环境 | https://gw.open.icbc.com.cn/api/jft/api/user/edpopenacct/query/V1 |

## 3. 通用请求参数

| 参数名 | 类型 | 是否必输 | 最大长度 | 描述 | 示例值 |
| --- | --- | --- | --- | --- | --- |
| app_id | str | true | 20 | APP的编号，应用在API开放平台注册时生成 | 10000000000000005402 |
| msg_id | str | true | 40 | 平台商户发起消息通讯的唯一编号，API接口生成，无需商户赋值，按规范调用接口即可 | 1506504665696 |
| format | str | false | 5 | 请求参数格式，仅支持json | json |
| charset | str | false | 10 | 字符集，缺省为UTF-8 | UTF-8 |
| sign_type | str | false | 5 | 平台商户在API开放平台注册时选择的签名类型，缺省为RSA2 | RSA、RSA2、EM-SM、CA、EM、SM |
| sign | str | true | 300 | 报文签名：API后台通过私钥跟加密密钥生成的签名，无需接口调用者调用接口时赋值 | - |
| timestamp | str | true | 19 | 交易发生时间戳，yyyy-MM-dd HH:mm:ss格式 | 2016-10-29 20:44:38 |
| biz_content | str | true | - | 请求参数的集合 | 参看[请求示例](#8-请求示例) |

## 4. 请求参数(biz_content节点内容)

| 参数名 | 类型 | 是否必输 | 最大长度 | 描述 | 示例值 | 备注 |

| appId | str | true | 20 | 合作方编号 | 10000000000000261019 | 应用在API开放平台注册时生成；同通用请求参数中的app_id |
| appIdSub | str | true | 20 | 付方平台外部编号 | SH000001 | - |
| outUserId | str | true | 20 | 外部用户编号 | 123456789 | - |

## 11. 返回码解释

### 11.1 常见异常码

| 返回码 | 返回说明 |
| --- | --- |
| -1 | 请求异常，请联系工行管理员 |
| -31 | 响应请求转换失败 |
| -30 | 服务方响应状态错误 |

| --- | --- |
| 400011 | 参数非法，原因可能为app id为空、app id非法、签名为空、应用系统时间与API平台系统时间不在限定差值以内、时间戳非法 |
| 500018 | 访问的API不存在 |
| 500020 | 非法调用 |
| 400016 | app公钥未维护 |
| 400017 | 签名验证失败 |
| 400019 | 授权验证失败 |
| 500031 | 速率超限 |
| 500032 | 并发超限 |
| -500041 | 代理异常 |
| -500042 | 代理超时 |
| -500044 | 网关签名失败 |
| 500043 | 网关配置文件错误，无法从配置文件中读取配置 |
