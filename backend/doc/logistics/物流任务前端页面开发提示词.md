# 物流任务前端页面开发详细提示词

## 1. 概述

本文档为物流运输任务模块的前端页面开发提供详细的提示词，包括页面布局、字段定义、表单设计、交互流程等具体实现细节。

## 2. 回收企业管理端 - 物流任务管理

### 2.1 物流任务列表页面

**页面路径**: `/logistics/transport-task/index`

**提示词**:
```
开发一个物流运输任务管理列表页面，具体要求如下：

【页面布局】
- 顶部搜索区域（可折叠）
- 中间操作按钮区域（新增、批量删除、导出等）
- 主体表格区域
- 底部分页组件

【搜索表单字段】
1. 任务编号 (task_no) - 输入框，支持模糊搜索
   - 占位符：请输入任务编号
   - 验证规则：/^[A-Z0-9\-]{0,64}$/
2. 订单编号 (order_no) - 输入框，支持模糊搜索
   - 占位符：请输入订单编号
   - 验证规则：/^[A-Z0-9\-]{0,64}$/
3. 任务状态 (task_status) - 下拉选择框
   - 接口地址：GET /system/dict-data/type/transport_task_status
   - 选项：全部、待分配(0)、已分配(1)、已接受(2)、运输中(3)、已取货(4)、已送达(5)、已完成(6)、已取消(7)
4. 车辆ID (vehicle_id) - 下拉选择框，可搜索
   - 接口地址：GET /logistics/vehicle/list-simple
   - 显示格式：车牌号 - 车辆类型
   - 支持按车牌号搜索
5. 司机ID (driver_id) - 下拉选择框，可搜索
   - 接口地址：GET /logistics/driver/list-simple
   - 显示格式：司机姓名 - 手机号
   - 支持按姓名搜索
6. 所属企业 (enterprise_id) - 下拉选择框
   - 接口地址：GET /system/enterprise/list-simple?type=logistics
   - 显示格式：企业名称 - 企业类型
   - 支持搜索过滤
7. 危废代码 (waste_code) - 输入框
   - 占位符：请输入危废代码
   - 验证规则：/^[A-Z0-9\-]{0,50}$/
8. 危废名称 (waste_name) - 输入框，支持模糊搜索
   - 占位符：请输入危废名称
   - 验证规则：/^[\u4e00-\u9fa5a-zA-Z0-9\s\(\)\-]{0,100}$/
9. 是否异常 (is_abnormal) - 单选框：全部/正常/异常
   - 默认值：全部
10. 是否临时任务 (is_temporary) - 单选框：全部/正常任务/临时任务
    - 默认值：全部
11. 分配时间范围 (assign_time) - 日期时间范围选择器
    - 格式：YYYY-MM-DD HH:mm:ss
    - 前端处理：开始时间和结束时间分别格式化
    - 默认范围：最近30天
12. 预计取货时间范围 (expected_pickup_time) - 日期时间范围选择器
    - 格式：YYYY-MM-DD HH:mm:ss
    - 前端处理：开始时间和结束时间分别格式化
13. 预计送达时间范围 (expected_delivery_time) - 日期时间范围选择器
    - 格式：YYYY-MM-DD HH:mm:ss
    - 前端处理：开始时间和结束时间分别格式化

【表格列定义】
1. 任务编号 (task_no) - 链接，点击查看详情
2. 订单编号 (order_no) - 链接，点击跳转订单详情
3. 任务状态 (task_status) - 状态标签，不同状态不同颜色
4. 车牌号 (vehicle_no) - 从车辆信息关联显示
5. 司机姓名 (driver_name) - 从司机信息关联显示
6. 取货企业 (pickup_enterprise_name) - 企业名称
7. 送货企业 (delivery_enterprise_name) - 企业名称
8. 危废名称 (waste_name)
9. 预估数量 (estimated_quantity) - 数字，带单位
10. 实际数量 (actual_quantity) - 数字，带单位，可能为空
11. 分配时间 (assign_time) - 日期时间格式
12. 预计取货时间 (expected_pickup_time) - 日期时间格式
13. 实际取货时间 (actual_pickup_time) - 日期时间格式，可能为空
14. 预计送达时间 (expected_delivery_time) - 日期时间格式
15. 实际送达时间 (actual_delivery_time) - 日期时间格式，可能为空
16. 是否异常 (is_abnormal) - 异常标识图标
17. 是否临时 (is_temporary) - 临时任务标识
18. 操作列 - 查看、编辑、删除、分配、取消等按钮

【操作按钮】
- 新增任务：打开新增表单弹窗
- 批量删除：选中多行后批量删除
- 导出Excel：导出当前搜索条件下的数据
- 刷新：重新加载数据

【行操作按钮】
- 查看详情：打开详情弹窗或跳转详情页
- 编辑：打开编辑表单弹窗（仅待分配状态可编辑）
- 删除：删除任务（仅待分配状态可删除）
- 分配任务：打开分配表单弹窗（仅待分配状态）
- 取消任务：取消任务（已完成状态不可取消）
- 查看轨迹：查看运输节点记录
- 查看位置：在地图上显示当前位置（运输中状态）

【状态颜色定义】
- 待分配：灰色 #909399
- 已分配：蓝色 #409EFF  
- 已接受：绿色 #67C23A
- 运输中：橙色 #E6A23C
- 已取货：紫色 #9C27B0
- 已送达：青色 #17A2B8
- 已完成：成功绿 #67C23A
- 已取消：红色 #F56C6C

【权限控制】
- 查询权限：logistics:transport-task:query
- 新增权限：logistics:transport-task:create
- 编辑权限：logistics:transport-task:update
- 删除权限：logistics:transport-task:delete
- 导出权限：logistics:transport-task:export
- 分配权限：logistics:transport-task:assign
- 取消权限：logistics:transport-task:cancel
```

### 2.2 物流任务新增/编辑表单

**提示词**:
```
开发物流运输任务的新增和编辑表单弹窗，具体要求如下：

【表单布局】
采用弹窗形式，分为多个区域：
1. 基本信息区域
2. 取货信息区域  
3. 送货信息区域
4. 货物信息区域
5. 其他信息区域

【基本信息区域字段】
1. 任务编号 (task_no) - 输入框，新增时自动生成，编辑时只读
2. 关联订单 (order_id) - 下拉选择框，可搜索订单号，必填
   - 显示格式：订单号 - 产废企业名称
   - 选择后自动填充相关信息
3. 所属企业 (enterprise_id) - 下拉选择框，物流公司列表，必填

【取货信息区域字段】
1. 取货企业 (pickup_enterprise_id) - 下拉选择框，必填
   - 接口地址：GET /system/enterprise/list-simple
   - 显示格式：企业名称 - 企业类型
   - 支持搜索过滤
   - 选择后自动填充省市区、详细地址、联系人、联系电话
2. 取货省份 (pickup_province) - 下拉选择框，必填
   - 接口地址：GET /system/area/province
   - 选择后自动加载对应城市列表
3. 取货城市 (pickup_city) - 下拉选择框，必填
   - 接口地址：GET /system/area/city?provinceId={provinceId}
   - 选择后自动加载对应区县列表
4. 取货区县 (pickup_district) - 下拉选择框，必填
   - 接口地址：GET /system/area/district?cityId={cityId}
5. 取货详细地址 (pickup_address) - 文本域，必填，最大500字符
   - 占位符：请输入详细地址（街道、门牌号等）
6. 取货联系人 (pickup_contact_name) - 输入框，必填，最大64字符
   - 验证规则：/^[\u4e00-\u9fa5a-zA-Z\s]{2,64}$/（中英文姓名）
7. 取货联系电话 (pickup_contact_phone) - 输入框，必填
   - 验证规则：/^1[3-9]\d{9}$/（手机号）或 /^0\d{2,3}-?\d{7,8}$/（座机号）
   - 错误提示：请输入正确的手机号或座机号
8. 预计取货时间 (expected_pickup_time) - 日期时间选择器，必填
   - 格式：YYYY-MM-DD HH:mm:ss
   - 前端处理：使用 dayjs 格式化为 'YYYY-MM-DD HH:mm:ss'
   - 限制：不能早于当前时间，不能晚于预计送达时间
   - 默认值：当前时间 + 2小时

【送货信息区域字段】
1. 送货企业 (delivery_enterprise_id) - 下拉选择框，必填
   - 接口地址：GET /system/enterprise/list-simple
   - 显示格式：企业名称 - 企业类型
   - 支持搜索过滤
   - 选择后自动填充省市区、详细地址、联系人、联系电话
2. 送货省份 (delivery_province) - 下拉选择框，必填
   - 接口地址：GET /system/area/province
   - 选择后自动加载对应城市列表
3. 送货城市 (delivery_city) - 下拉选择框，必填
   - 接口地址：GET /system/area/city?provinceId={provinceId}
   - 选择后自动加载对应区县列表
4. 送货区县 (delivery_district) - 下拉选择框，必填
   - 接口地址：GET /system/area/district?cityId={cityId}
5. 送货详细地址 (delivery_address) - 文本域，必填，最大500字符
   - 占位符：请输入详细地址（街道、门牌号等）
6. 送货联系人 (delivery_contact_name) - 输入框，必填，最大64字符
   - 验证规则：/^[\u4e00-\u9fa5a-zA-Z\s]{2,64}$/（中英文姓名）
7. 送货联系电话 (delivery_contact_phone) - 输入框，必填
   - 验证规则：/^1[3-9]\d{9}$/（手机号）或 /^0\d{2,3}-?\d{7,8}$/（座机号）
   - 错误提示：请输入正确的手机号或座机号
8. 预计送达时间 (expected_delivery_time) - 日期时间选择器，必填
   - 格式：YYYY-MM-DD HH:mm:ss
   - 前端处理：使用 dayjs 格式化为 'YYYY-MM-DD HH:mm:ss'
   - 限制：不能早于预计取货时间，建议比预计取货时间晚4-8小时
   - 默认值：预计取货时间 + 4小时

【货物信息区域字段】
1. 危废代码 (waste_code) - 输入框，必填，最大50字符
   - 验证规则：/^[A-Z0-9\-]{3,50}$/（大写字母、数字、连字符）
   - 占位符：如：HW01、HW02-001等
   - 支持下拉选择常见危废代码
   - 接口地址：GET /waste/code/list-simple
2. 危废名称 (waste_name) - 输入框，必填，最大100字符
   - 验证规则：/^[\u4e00-\u9fa5a-zA-Z0-9\s\(\)\-]{2,100}$/
   - 根据危废代码自动匹配填充
   - 支持手动修改
3. 预估数量 (estimated_quantity) - 数字输入框，必填
   - 验证规则：/^\d+(\.\d{1,2})?$/（最多2位小数）
   - 数值范围：0.01 - 999999.99
   - 输入限制：只能输入数字和小数点
   - 错误提示：请输入有效的数量（最多2位小数）
4. 数量单位 (quantity_unit) - 下拉选择框，必填
   - 接口地址：GET /system/dict-data/type/waste_quantity_unit
   - 选项：吨(t)、千克(kg)、立方米(m³)、升(L)、桶、袋、箱、个等
   - 默认值：吨(t)

【其他信息区域字段】
1. 是否临时任务 (is_temporary) - 单选框，默认否
2. 备注 (remark) - 文本域，最大500字符

【表单验证规则】
1. 必填字段验证：所有标记为必填的字段不能为空
2. 手机号格式验证：/^1[3-9]\d{9}$/（手机号）或 /^0\d{2,3}-?\d{7,8}$/（座机号）
3. 姓名格式验证：/^[\u4e00-\u9fa5a-zA-Z\s]{2,64}$/（中英文姓名，2-64字符）
4. 危废代码验证：/^[A-Z0-9\-]{3,50}$/（大写字母、数字、连字符）
5. 数量格式验证：/^\d+(\.\d{1,2})?$/（正数，最多2位小数，范围0.01-999999.99）
6. 时间逻辑验证：
   - 预计取货时间不能早于当前时间
   - 预计送达时间必须晚于预计取货时间
   - 时间间隔建议不少于2小时
7. 字符长度验证：各字段严格按照最大长度限制
8. 省市区联动验证：必须按层级选择，不能跳级

【表单交互逻辑】
1. 选择订单后，自动填充相关信息：
   - 调用接口：GET /waste/order/get/{orderId}
   - 自动填充：取货企业、取货省市区、取货地址、取货联系人、联系电话
   - 自动填充：危废代码、危废名称、预估数量、数量单位
2. 选择取货企业后，自动填充企业信息：
   - 调用接口：GET /system/enterprise/get/{enterpriseId}
   - 自动填充：省份、城市、区县、详细地址、联系人、联系电话
3. 选择送货企业后，自动填充企业信息：
   - 调用接口：GET /system/enterprise/get/{enterpriseId}
   - 自动填充：省份、城市、区县、详细地址、联系人、联系电话
4. 省市区联动逻辑：
   - 选择省份后，清空并重新加载城市列表
   - 选择城市后，清空并重新加载区县列表
   - 选择区县后，可以填写详细地址
5. 时间联动逻辑：
   - 预计取货时间变更时，自动调整预计送达时间（+4小时）
   - 实时验证时间间隔是否合理
6. 危废信息联动：
   - 危废代码输入时，自动匹配危废名称
   - 调用接口：GET /waste/code/get-by-code/{wasteCode}
7. 表单提交前校验：
   - 所有必填字段完整性检查
   - 格式验证（手机号、数量、时间等）
   - 逻辑验证（时间先后顺序、省市区完整性）
   - 数据一致性检查

【按钮操作】
- 确定：提交表单，成功后关闭弹窗并刷新列表
- 取消：关闭弹窗，不保存数据
- 重置：清空表单内容（仅新增时显示）
```

### 2.3 物流任务详情页面

**提示词**:
```
开发物流运输任务详情页面，具体要求如下：

【页面布局】
- 顶部面包屑导航
- 任务基本信息卡片
- 任务进度时间轴
- 取货送货信息卡片
- 货物信息卡片
- 运输轨迹卡片
- 异常信息卡片（如有异常）
- 操作按钮区域

【任务基本信息卡片】
显示字段：
1. 任务编号 (task_no) - 大号字体显示
2. 订单编号 (order_no) - 链接，可跳转订单详情
3. 任务状态 (task_status) - 状态标签
4. 所属企业 (enterprise_name) - 物流公司名称
5. 分配时间 (assign_time) - 日期时间
6. 接受时间 (accept_time) - 日期时间，可能为空
7. 是否异常 (is_abnormal) - 异常标识
8. 是否临时任务 (is_temporary) - 临时任务标识
9. 创建时间 (create_time) - 日期时间
10. 更新时间 (update_time) - 日期时间

【任务进度时间轴】
显示运输各个阶段的进度：
1. 任务创建 - 显示创建时间
2. 任务分配 - 显示分配时间和分配的车辆司机信息
3. 任务接受 - 显示接受时间
4. 开始运输 - 显示开始时间
5. 到达取货点 - 显示到达时间和位置
6. 取货完成 - 显示完成时间和实际装货量
7. 运输中 - 显示当前位置（如果在运输中）
8. 到达送货点 - 显示到达时间和位置
9. 送货完成 - 显示完成时间和实际卸货量
10. 任务完成 - 显示完成时间

每个节点显示：
- 节点名称和状态图标
- 操作时间
- 操作人员
- 位置信息（如有）
- 相关照片（如有）
- 备注信息（如有）

【取货送货信息卡片】
分为两列显示：

取货信息：
1. 取货企业 (pickup_enterprise_name)
2. 取货地址 (pickup_address)
3. 取货联系人 (pickup_contact_name)
4. 取货联系电话 (pickup_contact_phone)
5. 预计取货时间 (expected_pickup_time)
6. 实际取货时间 (actual_pickup_time)

送货信息：
1. 送货企业 (delivery_enterprise_name)
2. 送货地址 (delivery_address)
3. 送货联系人 (delivery_contact_name)
4. 送货联系电话 (delivery_contact_phone)
5. 预计送达时间 (expected_delivery_time)
6. 实际送达时间 (actual_delivery_time)

【货物信息卡片】
1. 危废代码 (waste_code)
2. 危废名称 (waste_name)
3. 预估数量 (estimated_quantity) + 单位
4. 实际装货数量 (actual_quantity) + 单位
5. 数量差异 - 计算显示差异值和百分比
6. 运输损耗率 - 如果任务完成，显示损耗率

【车辆司机信息卡片】
1. 车辆信息：
   - 车牌号 (vehicle_no)
   - 车辆类型 (vehicle_type)
   - 载重能力 (capacity_kg)
2. 司机信息：
   - 司机姓名 (driver_name)
   - 司机电话 (driver_phone)
   - 驾驶证号 (driver_license)

【运输轨迹卡片】
1. 地图显示：
   - 取货点标记
   - 送货点标记
   - 运输路线
   - 当前位置（如在运输中）
   - 历史轨迹点
2. 轨迹列表：
   - 按时间倒序显示所有节点记录
   - 每条记录显示：时间、位置、操作类型、操作人、备注

【异常信息卡片】（仅异常任务显示）
1. 异常类型 (abnormal_type) - 显示异常类型名称
2. 异常原因 (abnormal_reason) - 异常描述
```

```javascript
// 1. 时间选择器配置
const dateTimePickerConfig = {
  format: 'YYYY-MM-DD HH:mm:ss',
  valueFormat: 'YYYY-MM-DD HH:mm:ss',
  placeholder: '请选择时间'
}

// 2. 提交前时间格式化
import dayjs from 'dayjs'

// 格式化单个时间
const formatDateTime = (date) => {
  return dayjs(date).format('YYYY-MM-DD HH:mm:ss')
}

// 格式化时间范围
const formatDateTimeRange = (dateRange) => {
  if (!dateRange || dateRange.length !== 2) return []
  return [
    dayjs(dateRange[0]).format('YYYY-MM-DD HH:mm:ss'),
    dayjs(dateRange[1]).format('YYYY-MM-DD HH:mm:ss')
  ]
}

// 3. 表单提交示例

  const formData = {
    ...form.value,

    expected_delivery_time: formatDateTime(form.value.expected_delivery_time),
    assign_time_range: formatDateTimeRange(form.value.assign_time_range)
```
