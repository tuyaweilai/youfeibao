# 物流运输模块开发提示词文档（改进版 V2.1）

## 1. 引言

本文档为"危废再生资源全流程追溯SaaS平台"的物流运输模块提供全面的前后端开发任务提示词。基于复审改进后的API需求清单，提供更详细、更实用的开发指导。

## 2. 后端开发提示词 (Backend Prompts)

### 2.1 核心业务逻辑与API实现

#### 2.1.1 运输任务管理模块

**1. 运输任务创建与分配系统**
```
提示词：实现运输任务的完整生命周期管理：
1. 创建任务接收API（/transport-tasks POST）：接收危废模块的运输需求，验证订单信息，生成唯一任务编号，初始化任务状态为"待分配"
2. 任务分配API（/transport-tasks/{taskId}/assign PUT）：支持手动分配和智能推荐分配，验证车辆和司机可用性，记录分配历史
3. 任务重新分配API（/transport-tasks/{taskId}/reassign PUT）：处理分配变更，保留变更历史，通知相关人员
4. 任务取消API（/transport-tasks/{taskId}/cancel PUT）：支持取消原因记录，处理已分配资源释放
5. 实现任务状态机管理，确保状态转换的合法性和一致性
6. 集成消息队列实现异步通知机制
```

**2. 司机任务操作系统**
```
提示词：开发司机端任务管理功能：
1. 司机任务列表API（/driver/tasks GET）：按状态分组显示任务，支持筛选和排序
2. 任务详情API（/driver/tasks/{taskId} GET）：提供完整的任务信息，包括路线规划建议
3. 接受/拒绝任务API：实现原子性操作，防止并发冲突，记录操作时间和原因
4. 任务开始API（/driver/tasks/{taskId}/start POST）：验证司机位置，更新任务状态
5. 实现任务超时机制，自动释放超时未接受的任务
6. 集成推送服务，实时通知司机新任务
```

#### 2.1.2 运输节点跟踪模块

**3. 运输节点上报系统**
```
提示词：构建高可靠的运输节点跟踪系统：
1. 节点上报API（/transport-tasks/{taskId}/nodes POST）：
   - 支持多种节点类型（接单、装货、在途、卸货等）
   - 自动验证节点顺序的合法性
   - 集成GPS坐标验证，防止虚假上报
   - 支持照片上传和压缩处理
   - 实现离线数据缓存和同步机制
2. 实时位置上报API（/transport-tasks/{taskId}/location POST）：
   - 支持批量位置数据上报
   - 实现轨迹数据压缩和存储优化
   - 集成地理围栏检测
3. 异常上报API（/transport-tasks/{taskId}/exception POST）：
   - 分类处理不同类型异常
   - 自动触发应急响应流程
   - 集成短信/邮件通知
4. 使用Redis缓存实时位置数据，提高查询性能
5. 集成时序数据库（如InfluxDB）存储轨迹数据
```

**4. 轨迹查询与分析系统**
```
提示词：开发轨迹数据查询和分析功能：
1. 运输轨迹查询API（/transport-tasks/{taskId}/track GET）：
   - 提供时间范围筛选
   - 支持轨迹数据可视化格式输出
   - 实现轨迹数据分页加载
2. 车辆实时轨迹API（/vehicles/{vehicleId}/track GET）：
   - 实时获取车辆当前位置和状态
   - 提供历史轨迹回放功能
3. 批量轨迹查询API（/transport-tasks/track/batch POST）：
   - 支持多任务轨迹并行查询
   - 实现查询结果缓存优化
4. 集成地图服务API，提供路径规划和导航功能
5. 实现轨迹数据压缩算法，减少存储空间
```
