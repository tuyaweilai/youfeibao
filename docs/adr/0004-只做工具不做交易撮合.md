# 一期只做工具，不做交易撮合

平台是回收企业的作业系统，只覆盖「回收企业 ← 自然人出售者」这一段。回收企业与用废企业之间的买卖不在平台上发生。

**不做**：卖方挂牌、买方询盘、报价与公开竞价、在线下单成交、履约跟踪与收货确认、质检争议裁定、结算担保与资金监管、信用评价、价格指数、物资处置（产废企业公开竞价），以及回收企业之间的货源共享与行情展示。

**做**：自然人主体准入、收购登记（磅单/货物/车牌）、收购合同、反向开票、付款、收购台账与五流证据归集。

**Considered Options**

- **做交易市场**。未采纳：① 税总 5 号公告第十七条要求的证据链只覆盖「回收企业 ↔ 出售者」，撮合在法定义务之外；② 对手是资环链金（交易额超 2000 亿元、近 400 家加工基地、央企，且被发改环资〔2025〕1745 号点名支持建设全国性功能性平台）；③ 问题域不同——工具是「记录已发生的事实」，撮合是「促成尚未发生的交易」，后者要处理定价、验货争议、履约违约、资金担保，与合规不是一个领域。
- **只做工具**。采纳。

**Consequences**

- 数据模型只需覆盖「回收企业 ↔ 自然人」，加上用废企业作为**受票方**的最小实体。用废企业角色存在（正向开票预留，见 ADR-0003），但只用于接收正向专票、查看批次溯源，不作为买方参与找货。
- 品类一期只做**再生资源报废产品**（工行 `specificElements=24` / `buyerInvTypeCode=04` / `businessType=0004`）。农产品收购、危废、报废机动车不做：农产品资质路径不落在税总 5 号公告第二条的三项条件里；危废与报废机动车需独立资质与完全不同的作业现场（拆解线 vs 打包站），资环链金自己也把它拆成独立的「秒收车」产品。
- 品类与场景做成配置，不写死在代码里。
- 将来要做市场，前置技术是正向开票，ADR-0003 已把数据模型的口留出来了，不需要重写。
