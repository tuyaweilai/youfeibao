# 代办税费申报是平台自持的派生工作流

回收企业必须为出售者**代办**增值税及附加税费、个人所得税：**次月申报期**（次月 15 日）前报送《代办税费报告表》《代办税费明细报告表》并缴款。逾期未缴，主管税务机关**暂停其反向开票资格**（税总 5 号公告第十一条）。工行只负责逐票缴税，**没有申报清单接口，也没有补缴与汇算清缴接口**（见 `docs/icbc/工行答复-2026-09-18.md` §七「业务问卷中仍未答的：代办税费与补缴」）。所以「本月要缴多少、还缺什么、差多少要补」是平台自己的责任。本 ADR 记录这套东西怎么存。

**决策**

- **申报清单是派生视图，不建汇总表**。`TaxDeclarationServiceImpl` 每次从当月 `icbc_invoice_order`（蓝票，**按开票日期**）与 `icbc_red_invoice`（红票，**上传成功且按红票日期**）按出售者归集，减去当月红冲，得出每人净销售额；与额度台账同一套「派生而非物化」的理由（见 ADR 0014）。
- **税率与期限是政策常量，集中一处** `IcbcTaxConstants`：增值税 1% / 3%、附加税费综合 6%（12% × 自然人减半）、经营所得个税预缴 0.5%、申报期次月 15 日、汇算清缴次年 3 月 31 日。税额只有这一个来源。
- **10 万元免征线按「自然人 × 月跨租户」判定**，复用额度台账的 `getCrossTenantMonthlyNetAmount`：同一个人在多家回收企业卖货，免征额度只有一份。但**计税金额只按本租户当月开票额**——「回收企业须按当月各自开票金额代办申报缴款」。
- **三态单向状态机**：`待申报 → 已申报待缴款 → 已缴款`。**「逾期」不是一个状态**，而是「未缴款且已过截止日」由时间推导（`daysLeft < 0`）；逾期即产出「可能被暂停开票资格」的预警。预警（申报期临近 / 逾期 / 数据不齐）与缺项清单一律**即时推导**，不落库，避免「定时任务没跑到就没有预警」。
- **已缴款的申报单不可改写**：重新计算发现正差额时，登记一条 **`icbc_tax_supplement`（需补缴）**，按 1% / 3% 分列累计。补缴是申报之后才暴露的差额，不能悄悄改动一份已归档的报告表。同一申报单同时只保留一条未缴清补缴，job 每日重算时**覆盖而非累加**，保证幂等。
- **凭证归档与发票关联**：缴款成功把 `voucherNo / voucherFileUrl` 写回申报单，并把申报覆盖到的每张票写入 **`icbc_tax_declaration_invoice`**（蓝票计入、红票冲减）。凭证因此可正查（申报单→发票）也可反查。
- **汇算清缴是「提醒 + 对账」而非代申报**：`icbc_settlement_reminder`（出售者 × 纳税年度）由 `AnnualSettlementReminderJob` 生成，对账单给出当年开票张数、金额、已预缴税费与个税，出售者可凭**免登录令牌**（`SETTLEMENT_STATEMENT`，复用公开令牌机制）自取。本产品不接站内信推送（与 #5 到期预警同一约定）。

**Considered Options**

- **物化一张 `icbc_tax_declaration` 之外的汇总表 / 或把税额写回每张票**：否决。税额随红冲、跨期调整而变，写回发票会在多处同步、迟早漂移；申报单一处派生即可。
- **把「逾期」做成一个由定时任务翻转的状态**：否决。任务漏跑一次，逾期就不再可见；时间推导不会失败。
- **申报单已缴款后允许直接改写并补差额**：否决。报告表已报送、凭证已归档，改写会破坏「凭证—发票—申报」的三方一致；补缴单独立更可审计。
- **按租户判定 10 万元免征线**：否决。免征线是自然人的，会把同一人的销售额拆到两个租户下重复享受免征。
- **汇算清缴由平台代申报**：否决。法律规定由出售者**自行**汇算清缴，平台只提供提醒与信息；越权代申报既无通道也不合规定。
- **派生视图 + 补缴落库 + 提醒落库**：采纳。

**Consequences**

- 「本月应缴多少」「还缺什么」「要补多少」的口径只在 `TaxDeclarationServiceImpl` 与 `IcbcTaxConstants`，要按地区 / 政策调整只改常量一处。
- 缺项清单把「票没开出来 / 缴税没结清 / 出售者身份不全 / 红冲没收口 / 征收率没识别」摆出来，其中**出售者身份不全**与**征收率未识别**会挡住申报，其余是提示。
- 10 万元免征线的跨租户口径依赖额度台账的滚动窗口（近 12 个月）；对超过 12 个月的历史月份，跨租户汇总不可得，免征线按本租户当月额近似判定。月度申报只涉及上月，实际不受影响。
- 申报单与补缴都带 `tenant_id`；汇算清缴对账单只统计**本租户**开给该出售者的票，跨企业的合并汇算仍由出售者在税务端完成。
