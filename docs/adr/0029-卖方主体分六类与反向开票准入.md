# 卖方主体分六类，反向开票的准入是「主体是自然人」的硬约束

采购侧多了"非自然人卖方"之后，最容易出的错是**用一个布尔值区分对手方**（自然人 / 企业），然后让个体户、个人独资企业这些"看起来像个人"的主体滑进反向开票通道。政策口径不支持这种划分。

**决策**

1. **卖方主体类型是独立字段，至少六态**：自然人 / 个体工商户 / 个人独资企业 / 合伙企业 / 企业法人 / 农民专业合作社。判定规则是**"是否属于自然人"**（《增值税法实施条例》第三条：个人包括个体工商户和自然人），而不是"有没有营业执照"。
2. **反向开票通道的准入写成硬约束"主体 = 自然人"**，由系统拦，不靠操作员判断。法源：国家税务总局公告 2024 年第 5 号第一条把出售者定义为"**自然人**"，且第三条要求引导持续出售的自然人**依法办理经营主体登记、自行开具发票**。
3. **非自然人卖方走独立的收票链路**：收票登记 → 验真 → 票种判定（专票 / 普票）→ 抵扣资格标记。个体户、个独、合伙、企业、合作社各自自开票；**回收企业不为它们开票**。
4. **票种与计税方法强耦合**：回收企业就销售报废产品选择简易计税时，反向开票只能开**普票**；一般计税才能开专票。这条绑死在开票适配器里，不做成配置项。
5. **"能不能抵"是双条件**：票种是专票 **且** 回收企业自身不是简易计税 / 免税项目。
6. **税前扣除凭证的兜底是两套**：非自然人卖方适用"补开、换开 + 特殊原因"那套救济；自然人反向开票没有这个缺口。补救流程不能共用一套。

**必须分开建模的一个高频混淆**

- 个体工商户**不能**作为出售者被反向开票（它不属于自然人）。
- 个体工商户**能**作为**回收企业**去反向开票——5 号公告第二条的"资源回收企业"原文即"包括单位和个体工商户"，官方解读也明确。

这两句话在代码里是两个位置（前者是卖方的准入，后者是租户的资格），混起来会写出一个既拦错人又放错人的门禁。

**Consequences**

- 采购单上的"交易对方"要有主体类型字段（见 [ADR 0027](./0027-采购与仓储的对象模型.md) 的双外键承载），主体类型决定走哪条取票链路。
- 个体户能否作为出售者，**结论是推断**（由 5 号公告第一条 + 实施条例第三条推出），**没有明文写"个体工商户不得被反向开票"**。落地前应向主管税务机关确认，并确认"自然人超 500 万转登记为个体户后同一主体如何衔接"。
- 自然人在报废产品交易中能否取得**代开专票**，现行依据只到"其他个人被排除在自开专票之外"，代开口径未核实。若实际可代开专票，"代开普票不可抵"这一行要改。
- **一个新变量要盯**：财政部 税务总局公告 2026 年第 28 号《境内单位代扣代缴自然人增值税管理办法》，**2026-11-01 起施行**，正文（PDF 附件）因 WAF 未取得，其与"反向开票 / 代开发票"的衔接规则未知。若它把回收企业设为向自然人付款的**扣缴义务人**，会同时影响付款链路（工行公对私直付）与代办税费，需要在生效前拿到正文核对。**距今约六周。**
