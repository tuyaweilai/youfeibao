# 自然人端信息架构：底部导航「首页 / 交易 / 我的」，发票税费独立成页

**状态**：已定（2026-09-22，来自用户对 H5 排版问题的现场反馈）

#34（S4）把自然人端的「待我确认 / 我的记录 / 收款记录 / 发票税费 / 我的资料」做成了登录后首页（`pages/home/index`）里一排横向页签。一页塞六项，一屏放不下、只能横向滚动，用户实测反馈「排版有问题」。

**决策**

1. **底部导航（原生 tabBar）三项**：首页 `pages/home/index`、交易 `pages/transaction/index`、我的 `pages/my/index`。原横向页签整排取消，不再有「一页里再套一层全局导航」的结构。
2. **「交易」承接三块原样内容**：待我确认 / 我的记录 / 收款记录，作为该页内部三个等宽子页签（模板与接口都沿用 #34 的实现，只是换了位置）。首页「常用服务」里的三个入口直接落到对应子页签。
3. **发票税费独立成页** `pages/invoice/index`，**不进底部导航**：它是按年度翻阅的票据视图，不是每天进的入口。入口放在首页「常用服务」与我的页的入口格里。
4. **「我的」承载账户类内容**：我的资料、客服电话、收款账户与换卡、企业授权与撤销、退出登录，外加发票税费 / 我的预约两个入口。「我的预约」仍是普通页面（ADR 0020：预约不是订单，不占导航位）。
5. **跨页参数**：原生 `switchTab` 不能带 query，而两者性质不同，所以分开处理（`src/utils/nav.ts`）。
   - 「要预选哪个子页签」是**一次性**的，写本地存储、目标页取走即清。
   - 场站编号（`stationId`）是「**这次扫的是哪家场站的码**」的提示，只放内存、不进存储：刷新即清零，语义正好是「本次进屋」。
     它曾经落存储，结果变成跨天跨库的陈旧值（场站被删 / 换过库后前端仍拿着旧编号去请求，后端报「场站不存在」、首页 500）——用户 2026-09-22 实测踩到。
6. **场站编号只是提示，过期不得报错**：后端 `getHome` 用「查不到就返回 null」的 `getStationOrNull` 取场站，认不出来就**当没带**——不按它筛待办（否则会把待办筛成空、让人误以为没货）、不显示场站名，并且**不回给前端 `stationId`**，前端据此清掉本地提示。
7. **空态只有一份**：手机号验证过但一个主体都没绑上时，三页共用一个组件（`src/components/SellerNoProfile.vue`），不再各页各写一段。

**Considered Options**

- **自绘底部导航**：否决。能带 query、少一层参数传递，但要自己处理选中态、安全区与页面切换，小程序上还拿不到原生 tabBar 的切换动效；`stationId` 走内存变量的代价更小。
- **发票税费也进底部导航（四项）**：否决。用户口径是「独立页面」，且它一年才翻几次，不值得占常驻导航位。
- **把「我的资料」并入首页顶部的头像入口**：否决。保留独立一页，账户与授权类操作有稳定落点。

**Consequences**

- `pages/home/index` 从「什么都装」回到「首页」：问候、待办数、常用服务入口、最近两条待办、找不到入口时的说明。
- 底部导航图标是图片（原生 tabBar 不支持字体图标），产物入库、生成脚本一并入库（`scripts/gen-tabbar-icons.py`）。
- **改 `pages.json` 后必须重启 H5 开发服务器**，否则底部导航不出现：uni 把 `__UNI_FEATURE_TABBAR__` 这类特性开关在**启动那一刻**算好写进服务端返回的代码里，重启前它恒为 false（页面能正常渲染，但 `uni-tabbar` 不渲染、`--window-bottom` 为 0）。构建产物不受影响。同理，`uni.scss` 的变量也是在启动时读进内存的：改了 `uni.scss` 不重启，新变量在页面里就是 `Undefined variable`，页面会白屏并报「连接服务器超时，点击屏幕重试」（那是 uni 的动态 import 失败提示，不是网络毛病）——所以 `src/styles/seller-page.scss` 头部对用到的配色加了一层 `!default` 兜底。
- 后续再把东西塞进首页横向页签之前，先看本 ADR：常驻入口的空间是底部导航，不是页面顶部的滚动条。
- **客户端带来的编号一律当提示**（本 ADR 决策 6 的推广）：进门接口（首页 / 待我确认）不因一个过期提示把整个接口打成 500；要筛就筛，认不出来就当没带。
