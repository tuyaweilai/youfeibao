# 我们是平台方，开票主体是回收企业

平台不自持反向开票资质，也不以自己名义开票。反向开票的法律主体是使用平台的资源回收企业——国家税务总局公告 2024 年第 5 号第二条只把该资质授予「资源回收企业」，并要求其实际从事资源回收业务。

**Considered Options**

- **自营**：平台自己取得资源回收企业资质（危废经营许可证 / 报废机动车回收拆解资质 / 商务部再生资源回收经营者备案）与反向开票资格，自己开票。**未采纳**：等于转行做回收，需要实体回收业务与作业现场，与平台定位冲突，且每个品类都要独立资质。
- **平台方**：回收企业各自作为开票主体，平台提供系统与证据链。**采纳**。

**Consequences**

- 多主体是硬约束：每个回收企业有独立的资质、票种（简易计税仅普票 / 一般计税可开专票）、发票额度、纳税信用等级，全部要分开建模与校验。
- 平台要拿到开票能力，只有两条路：**自建乐企联用直连资质**，或**借道已持有该资质的单位**（工商银行是首批获得「乐企联用」反向开票资质的商业银行）。此决策另记。
- 开票的法律责任在回收企业；但平台若成为直连单位，会额外承担一套独立的监管义务与停服风险（见《乐企联用规范指引》）。
