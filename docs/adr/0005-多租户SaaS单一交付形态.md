# 一期只提供多租户 SaaS，不做按回收企业私有化部署

平台以单实例多租户形态交付，回收企业注册即可使用。不给单个回收企业做私有化部署。

**Considered Options**

- **按企业私有化部署**。未采纳：每家回收企业会成为各自独立的接入实体，要各自与工行签约、各自开立子商户档案、各自走一遍准入——平台作为「合作方」的规模价值随之消失。
- **多租户 SaaS**。采纳。

**Consequences**

- 每个回收企业是独立租户，各自拥有独立的主体资质、票种（简易计税仅普票 / 一般计税可开专票）、发票额度、纳税信用等级，全部分开建模与校验。
- 工行侧对应关系：一家回收企业一个**子商户档案**（`archiveType=01`），平台持有 `appId`。
- 竞品开灵科技对外提供「私有化独立部署」，那是因为它不持有开票接入角色；本项目不适用同一个选择。
- 为地方政府或园区做专有部署是另一件事，不在此决策范围内，后续另议。
