# 个人主动发起是到站预约，不是订单

**状态**：已定（2026-09-19）

自然人端要支持「个人主动发起：选择回收企业、货物品类，填写预计数量和车牌」。若这是一张企业必须接受的**订单**，就会引入接单、拒单、超时、定价权，那是撮合——与 ADR 0004「只做工具不做交易撮合」和 ADR 0007「采集责任归回收企业」直接冲突。

**决策**

- 新增 **预约到站**（`icbc_appointment`）：出售者 + 场站 + 品类 + 预计数量（**可空**）+ 车牌 + 预计到站时间。
- 它**不是合同、不占额度、不产生开票、不进五流**。
- 到站后仍由收货员建收购单；预约只用于**带出与排队**，预计数量在界面上必须以「约」标注。

**Consequences**

- 预计数量通常不准，因此任何**统计与额度口径都不得引用预约数据**（额度只认收购单与发票事实）。
- 预约的价值是减少到站后的重复填写，不是促成交易；因此没有「企业接受/拒绝」动作，只有「到场」与「未到场」。
- 若将来真要做撮合，前置是重新审视 ADR 0004，而不是给预约加上接单动作。
