# 平台不持有资金、不垫资

平台绝不代收代付、不建资金池、不为回收企业垫付货款。收购款从回收企业的银行账户经工行直付或智慧清分划付给出售者；平台只代回收企业发起支付指令，并归集支付状态与回单。

**Considered Options**

- **平台代收代付并结算给出售者**。未采纳：可能构成无证从事支付结算业务（「二清」），属刑事级风险；且资金池会把平台的资产负债与回收企业绑定。
- **银行直连/清分，平台只做指令与状态**。采纳。

**Consequences**

- 付款必须由平台代回收企业发起（调用工行「开票付方支付接口」生成企业支付页面），否则平台拿不到 `payStatus` 状态机与转账回单，五流中的**资金流**会断链——而五流齐备正是本平台的交付物。若改为回收企业自行在工行网银操作，此决策需重新评估。
- 出售者收款走工行电子钱包/智慧清分（`receiverType=03 自然人`、`accountKind=02 个人`），平台不落地资金。
- 平台不为回收企业垫资，因此不承担回收企业的信用风险，也不涉及融资业务的牌照问题。工行接口内建的融资能力（`loanApplyNo`、`repaidPriAndIntAmount`、`payMode=42 新经营快贷`）由工行作为放款方承担风险，平台最多做信息通道，不在本决策内自行放款。
- 平台侧不得为实现「开票即付款」而引入自有账户过渡，即使是一日内的过桥。
