# 卡证识别与电子签章各立出站端口，腾讯为目标供应商

**状态**：已定（2026-09-21）

ADR 0013 为收购现场的磅单与车牌识别立了 `AcquisitionRecognitionPort`，并定下三条：单列端口、默认空实现、业务层只依赖端口。`#81` 引入的身份证 / 银行卡识别与第三方电子签章是同类的外部依赖，但没有现成端口可用。

**决策**

1. **卡证识别另立端口**，不扩 `AcquisitionRecognitionPort`。现有那个端口的语义是「收购现场识别」，服务的是**货物流证据**（磅单、车牌）；身份证与银行卡服务的是**主体准入**。三条理由：消费者不同（建档流程 vs 收购登记）；失败语义相反（磅单识别失败不阻断、人工补录即可，银行卡识别失败直接挡住收方入驻）；供应商产品线不同（腾讯的卡证识别与车牌识别不是同一个产品）。新端口覆盖「识别身份证正面」「识别身份证反面」「识别银行卡」，默认 stub 返回空。
2. **电子签章另立端口**，覆盖「发起签署」「生成签署链接」「查询与下载已签文件」，默认 stub 使签章不可用（业务降级为 `PAPER`）。
3. **两个端口都不进 `IcbcGateway`**：后者是「平台对工行的唯一出站端口」（ADR 0009），ADR 0013 已就此定过一次边界，本条沿用同一条理由。
4. **目标供应商都是腾讯**（腾讯云 OCR / 腾讯电子签）。宿主是独立端口而不是具体 SDK，换供应商时业务层不动。
5. **证件影像不留存**：识别把结果写进档案，图片识别完即弃，不进文件服务、不进一票一档。工行收方入驻已改数据接口，不再需要上送影像。

**Considered Options**

- **并入 `IcbcGateway`**：否决。会让「工行」这条变更隔离带混入非工行依赖（ADR 0009 / 0013 同一理由）。
- **扩展 `AcquisitionRecognitionPort`**：否决，理由见决策 1 的三条不同。
- **在向导前端直连腾讯**：否决。密钥会落到前端，识别结果留痕与口径都不可控。

**Consequences**

- 未配置时的行为是明确的：卡证识别返回空、退化为手工录入（现场不断档）；签章不可用、协议落 `PAPER`。**两者都不阻断建档**。
- 后台要落配置项：OCR 的供应商 / 密钥 / 地域 / 超时；签章的平台级与租户级配置见 ADR 0036。
- 测试可用 mock 端口断言「识别结果只在空缺处回填、人工值优先」，不触网。

## 更正（#112，2026-09-22）：决策 1 的「供应商产品线不同」是错的

决策 1 给了三条理由，第三条「供应商产品线不同（腾讯的卡证识别与车牌识别不是同一个产品）」**不成立，予以撤回**：腾讯云的车牌识别是**同一个产品**下的另一个 action——`ocr` / `2018-11-19` 的 `LicensePlateOCR`，与 `IDCardOCR` / `BankCardOCR` 同一套 SecretId / SecretKey、同一个 endpoint、同一个账号的额度。因此 #112 把车牌识别接在 `AcquisitionRecognitionPort` 上时，**直接复用了卡证识别那份平台配置**（`icbc_card_recognition_config`、同一个 `provider` 开关、同一页后台运营配置），没有再开第二份密钥与第二个开关。

**端口分离的结论不变**，因为它靠的是另外两条理由：

- 消费者不同：`CardRecognitionPort` 服务**主体准入**（建档向导），`AcquisitionRecognitionPort` 服务**货物流证据**（磅单、车牌）；
- 失败语义相反：银行卡识别失败会挡住收方入驻，车牌识别失败手工录入即可、不阻断登记。

另：两个端口的**入参口径现在也一致了**（都收 base64，见 ADR 0013 的修订），但这不是「理由消失」——一边是「影像不留存所以没有 URL」，一边是「识别不该依赖图片存在哪儿」，各自成立后碰巧同形。

随之而来的两处顺带改动：

- 连通性自检（#103）多探一路 `LicensePlateOCR`：腾讯云的识别接口**按接口开通**，未开通报 `FailedOperation.ServiceNotOpened`。新增分类 `SERVICE_NOT_OPENED`（「识别接口未开通」），不再把它当成「鉴权通过」——否则「自检通过」要到现场第一次拍车头照时才说谎。
- `TencentOcrClient.plainBase64`（剥 dataURL 前缀）从 `TencentCardRecognition` 提到客户端上：两个识别端口都要做这一步，判据只留一处。
