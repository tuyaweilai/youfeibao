## 一、实人认证

### （一）实人认证接口 (/ui/jft/ui/user/faceH5/submit/V1)

#### 1.报文格式：

示例：{ "appId": "", "transNode": "", "outUserId": "", "verifyResult": ""} 

#### 2.接收变量名：

biz_content

#### 3.报文内容：

#### 4.biz_content数据定义

#### 5.具体示例（仅供参考）

biz_content: {

    "appId": "10000000000000123456",  // 平台外部编号

    "transNo": "110000000000000303011740807742455897",        // 交易流水号

    "outUserId": "20230202123456",    // 外部用户编号

    "verifyResult": "1"                  // 审核结果

}

| key | 长度定义 | 说明 |
| --- | --- | --- |
| biz_content | 无限制 | 通知消息，json格式 |

| 变量名称 | 变量命名 | 变量类型 | 说明 |
| --- | --- | --- | --- |
| 平台外部编号 | appId | String | 一定返回，申请入参参数 |
| 交易流水号 | transNo | String | 一定返回，申请入参参数（长度不大于 36） |
| 外部用户编号 | outUserId | String | 一定返回，申请入参参数 |
| 实人认证校验结果 | verifyResult | String | 一定返回，通过为1，未通过为0 |
