# 再生资源回收企业回收方式研究

> 研究日期：2026-09-20  
> 范围：中国再生资源 / 废旧物资回收企业面向个人、商户、机关企事业单位的前端收货方式  
> 方法：只采用政府部门政策原文、政府 / 供销系统官方报道、企业官网或官方服务规则。引用编号 `[S1]`…`[S12]` 对应文末来源清单。  
> 与本项目的关系：本文解释行业全貌；是否进入 youfeibao，以现有 `CONTEXT.md` 与 ADR 为准。

## 0. 一句话结论

**【结论】理解方向是对的，但不能把“上门回收、客户预约、到站回收”当成三个平级类型。**

- **上门、固定地点、流动回收**回答的是“货在哪里交给回收企业”。国家规章明确列出这三类基本方式；地方条例也使用“固定站点、定时定点、上门回收”的分类。`[S1]` `[S2]`
- **预约、即时、定时定点**回答的是“何时、怎样发起和调度”。国家政策对互联网回收的标准表述是“网上 / 线上预约、上门 / 线下回收”。`[S3]` `[S4]`
- **居民回收、企业大宗、以旧换新**回答的是“什么业务场景、货从哪里来”。它们最后仍会落到上门、自送、门店、物流寄送等一种或多种交付方式。

因此，行业分类至少要分成三条轴，而不是一个下拉框：

| 分类轴 | 回答的问题 | 典型值 |
|---|---|---|
| 交付方式 | 货在哪里交接？ | 上门、到站 / 到店、社区点、智能箱、流动点、物流寄送 |
| 发起与时效 | 怎样触发、什么时候履约？ | 直接到场、预约、即时 / 加急、定时定点、周期计划 |
| 业务场景 | 谁因为什么交货？ | 自然人日常交售、专业出售者到站、单位大宗处置、以旧换新 |

## 1. 政策确认的基本边界

### 1.1 官方基本分类：上门、流动、固定地点

**【事实】**《再生资源回收管理办法》第十三条规定，再生资源回收可以采取“上门回收、流动回收、固定地点回收”等方式，并可通过电话、互联网与居民、企业建立信息互动。该办法第十六条同时说明，回收网点包括社区回收、中转、集散、加工处理等再生资源停留场所。`[S1]`

**【事实】**《北京市生活垃圾管理条例》进一步使用“固定站点回收、定时定点回收、上门回收”的表述。`[S2]`

**【推断】** 这说明：

1. “到站回收”在业务口语里成立；政策语言更常用“固定地点 / 固定站点回收”“回收交投点”。
2. “流动回收”不等于“逐户上门”。前者通常是回收车在约定时间停靠社区指定位置，出售者把货送到车旁；后者是回收人员到出售者家中或经营场所取货。
3. 中转站、分拣中心是后端物流节点，不应因为名字里有“站 / 中心”，就默认开放给出售者交货。

### 1.2 预约不是回收地点，而是发起方式

**【事实】** 国家发展改革委等部门提出，通过手机 APP、微信小程序等“实现网上预约、上门回收”；商务部等九部门使用“线上预约、线下回收”的表述。`[S3]` `[S4]`

**【事实】** 文山州供销系统的实际流程是：居民在小程序选择品类、填写地址，回收员上门，现场称重、核算、转账；平台承诺“24 小时内上门，最快 30 分钟响应”，并计划增加“上门加急、预约错峰回收”。`[S5]`

**【推断】** 因而“预约上门”和“即时上门”应共享一条上门履约主流程；差异只在服务时窗：

- **预约上门**：出售者选日期或时段，企业排班后履约。
- **即时 / 加急上门**：出售者要求尽快响应，企业按服务半径、运力和起收门槛派单。
- “30 分钟响应”不一定等于“30 分钟完成回收”，产品字段应区分响应承诺、预计到达时间和实际到达时间。

### 1.3 “点—站—场”是网络层级，不是三个客户入口

**【事实】** 商务部等九部门提出“社区回收点前端投放—街道中转站枢纽回收—区县分拣中心末端分拣”的三级体系。`[S4]` 中国资环驿站的官方报道也将数字化工具、移动回收站和绿色综合分拣中心连接为“点—站—场”体系。`[S6]`

**【推断】** 前台地图只能展示确实可交售的固定交投点 / 门店 / 场站；中转站、分拣中心若只承担内部周转，不应暴露为“到站回收”地址。

## 2. 市场上实际存在的回收方式

| 方式 | 典型流程 | 适用品类 / 场景 | 主要约束 | 类型判断 |
|---|---|---|---|---|
| **预约上门** | 线上 / 电话提交品类、数量、地址、时间 → 企业排班 → 上门查验、称重 / 估价 → 确认成交 → 搬运 | 大件家电家具、数量较多、行动不便、单位定期回收 | 路线密度、最低起收量、空驶、现场改价、拆装安全 | 交付方式 + 发起方式的组合 |
| **即时 / 加急上门** | 提交需求 → 系统匹配附近人员 → 尽快到达 → 现场成交 | 高密度城区、小中型标准品、紧急清场 | 运力与峰值波动；通常需加急费或更高起收门槛 | 上门回收的 SLA 变体，不宜单独建一套业务 |
| **到站 / 到店自送** | 出售者直接到场或先预约 → 排队 → 查验、过磅 → 定价确认 → 结算 | 专业出售者、商户、高频重复交售、车载废钢废纸等 | 场地资质、车辆排队、地磅与监控、现场安全 | 固定地点回收 `[S1]` `[S2]` |
| **社区人工回收点 / 临时存放点** | 居民送到社区点 → 人工称重或先暂存 → 集中清运 | 居民小批量、大件暂存、一刻钟生活圈 | 物业合作、消防、卫生、清运频次 | 固定地点回收的近场形态 `[S4]` |
| **智能回收箱** | 扫码 / 刷卡 → 选品类 → 开箱投递 → 自动称重 → 积分或返现 → 满仓预警与清运 | 废纸、塑料、织物、金属等小件、低值、高频品类 | 误投、掺杂、满溢、设备维护；不适合大件和需现场精细定级的货物 | 无人值守固定点 `[S7]` |
| **定时定点流动回收 / 以车代库** | 提前公布时间地点 → 回收车按班次进社区 → 居民送到车旁 → 即收即走 | 无固定场地、城乡集市、社区周期回收、大件集中日 | 路权、停车、天气、班次通知、错过班次 | 流动回收，不是逐户上门 `[S4]` |
| **物流寄送 / 快递回收** | 在线估价 → 快递上门取件或自行寄送 → 集中质检 → 确认终价 → 付款 | 手机、数码等小体积、高单价、易标准化检测品类 | 寄送风险、前后估价差异、退回、数据清除 | 第三方物流承运的远程交付 `[S8]` |
| **企业 / 机关事业单位大宗处置** | 资产清单 / 长期协议或公开询价 → 资质审查 → 现场踏勘 → 报价 / 竞价 → 合同 → 拆运、称重、交接、结算 | 办公设备、生产边角料、包装物、废旧设备、批量废金属 | 资质、保密、拆除施工、危废识别、运输、招采合规 | 业务场景，不是单一交付方式 `[S4]` `[S9]` `[S10]` |
| **以旧换新 / 逆向物流** | 购买新品时提交旧品 → 旧品估价 → 送新与收旧一次或两次上门，或门店 / 邮寄交旧 → 补贴与价款结算 | 家电、手机数码、汽车等耐用消费品 | 新旧订单关联、补贴核验、拆装、履约顺序 | 销售触发的获货场景，可组合多种交付方式 `[S11]` `[S12]` |

### 2.1 到站回收

**适合：** 高频、较大批量、出售者有车辆、需要地磅或现场快速分级的交易。专业出售者把收集到的货集中送到回收企业场站，是废钢、废纸、废塑料等传统大宗再生资源的常见形态。

**典型业务流程：**

1. 直接到场，或提前声明预计到站时间、品类、约量、车牌；
2. 门岗 / 收货员识别出售者与车辆；
3. 查验货物，拍摄车货，过毛重；
4. 卸货、分级、扣杂、过皮重；
5. 形成结算重量和价格，出售者确认；
6. 建立收购合同 / 协议，付款并开票；
7. 货物进入分拣、打包、存储或后续运输。

**【推断】** “预约到站”只减少排队和重复填报，不能提前锁定最终重量、等级或成交金额；这些事实必须以现场查验和过磅为准。

### 2.2 上门回收

**适合：** 出售者难以搬运的大件、家庭 / 商户集中清理、单位周期性积累、企业现场产生的批量物资。

**典型业务流程：**

1. 出售者提交品类、照片、约量、地址、楼层 / 装卸条件与期望时间；
2. 企业判断服务范围、起收门槛、预估价格和是否需要拆装；
3. 排班、路线规划、车辆与人员调度；
4. 到场核验身份和货物，现场称重 / 估价；
5. 双方确认最终数量、质量、价格和相关费用；
6. 搬运装车，生成交接与运输凭证；
7. 付款、开票，回场复核或入库。

**关键控制：** 预约描述不是成交事实；需留存预约版本与现场结果的差异。对需要回场地磅复秤的货物，还要明确以哪次计量为结算依据。

### 2.3 社区点、智能箱和流动回收

三者都靠近居民，但不要合并：

- **社区人工点**有人值守，能够初检、分品、处理咨询，也可作为大件临时存放点。
- **智能箱**是 24 小时自助投放设备。官方案例显示，常见流程是扫码、自动称重、实时计价 / 积分、满仓预警后派员清运。`[S7]`
- **流动回收车**按公布的时间和地点短暂停靠，官方文件称“以车代库”“定点、定时”“即收即走”。`[S4]`

### 2.4 企业大宗回收

**【事实】** 商务部政策要求回收企业与政府机关、企事业单位建立稳定合作关系，建设废旧办公设备和办公家具统一回收平台。`[S4]` 官方处置公告显示，一次性大宗处置还可能包括报名、资质审查、现场查验、含拆卸搬运运输等费用的报价、竞价、付款、限期清运和现场恢复。`[S9]`

**【推断】** 企业大宗回收通常有两种完全不同的入口：

- **周期协议回收**：合同约定品类、周期、计价规则和运输责任，按批次叫车 / 提货。
- **项目制处置**：一次资产包先询价或竞价，中选后再拆运交接。

前者可与上门调度复用；后者包含招采 / 竞价，不应伪装成普通上门预约。

### 2.5 以旧换新与逆向物流

**【事实】** 国务院行动方案支持耐用消费品生产、销售企业建设逆向物流体系，或与专业回收企业合作上门回收；同时提出推广报废汽车上门取车。`[S11]` 商务部政策也支持售后维修网络开展逆向物流。`[S4]`

**【事实】** 京东官方服务规则展示了三种履约顺序：“先回收、后送新”“先送新、后回收”“送新品、同时收旧品”，其中一次上门和两次上门都存在。`[S12]`

**【推断】** 所以“以旧换新”不是新的物理交付方式，而是旧品回收与新品销售、补贴、安装联动的业务场景。回收企业仍需记录旧品最终由谁、在何时何地、用什么方式接收。

## 3. 对 youfeibao 的渠道分类建议

### 3.0 当前代码的表达能力

**【代码事实，2026-09-20】** 当前 `IcbcAcquisitionDO` / `AcquisitionCreateReqVO`（分别位于 `dal/dataobject/acquisition/`、`controller/admin/acquisition/vo/`）已有：

- `stationId`：收购单所属场站，也是结算单按“出售者 + 场站”聚合的依据；
- `tradeAddress`：税务收购台账所需的交易地点文本；
- `tradeTime`：实际交易时间；
- 司机、车牌、磅单、车头车尾照片等运输与货物流证据。

预约记录 `IcbcAppointmentDO` 也已有 `stationId`、预计到站时间、约量和车牌，并明确约量不参与计价与统计。**但收购单目前没有显式的“交付方式 / 回收方式”字段。** 换言之，当前代码能够表达“在哪个场站、什么地址发生了交易”，却不能可靠区分“出售者自送到站”与“回收企业上门取货”；不能用 `stationId != null` 或 `tradeAddress` 文本反推回收方式，因为未来上门业务也可能归属某个运营场站。

这不是一期缺陷：当前业务本来就只有到站主链路。它只是意味着，未来真正引入上门回收前，应先新增显式的交付方式，而不是靠地址或是否有预约推断。

### 3.1 不要做成一个 `回收方式` 枚举

建议至少拆成以下四组字段：

| 字段组 | 建议值 | 说明 |
|---|---|---|
| **交付方式** | `SITE_DELIVERY` 到站自送；`DOORSTEP_PICKUP` 上门取货；预留 `COMMUNITY_POINT`、`SMART_BOX`、`MOBILE_POINT`、`LOGISTICS_SEND_IN` | 记录货物交接的物理方式，是业务真实性证据的一部分 |
| **发起方式** | `WALK_IN` 直接到场；`SELLER_APPOINTMENT` 出售者预约；`ENTERPRISE_SCHEDULE` 回收企业安排；`PERIODIC_PLAN` 周期计划；`TRADE_IN_TRIGGER` 换新触发 | 预约不是订单，也不代表企业已经接受交易 |
| **服务时效** | `SCHEDULED` 预约时段；`ON_DEMAND` 即时 / 加急；`FIXED_TIMETABLE` 固定班次 | 即时只是调度承诺；保留预计 / 实际到达时间 |
| **来源场景** | `INDIVIDUAL_PROFESSIONAL` 专业自然人出售者；预留 `RESIDENT` 普通居民、`MERCHANT` 商户、`INSTITUTION_BULK` 单位大宗、`TRADE_IN` 以旧换新 | 决定准入、开票和交互流程，不能由交付方式推断 |

另外单独记录：

- **交易事实地点**：场站 ID，或上门地址 + 经纬度 + 到场留痕；
- **履约时间**：申请时间、预约时段、接单 / 排班时间、预计到达、实际到达、完成时间；
- **物资流向节点**：交投点、中转站、分拣中心、加工处理场。这是物流网络，不是出售者渠道；
- **承运责任**：出售者自运、回收企业自运、第三方承运，并关联运输凭证。

### 3.2 一期建议：只把“到站自送”做深

**【建议】** 结合现有 ADR，一期主渠道应为：

> 专业自然人出售者 → 直接到站或预约到站 → 收货员现场建收购单 → 过磅 / 扣杂 / 定价 → 结算确认 → 付款与反向开票。

理由：

1. ADR 0007 已把一期对象限定为高频、重复交售的专业出售者，而非偶尔卖一次废品的普通居民。
2. ADR 0020 已定义“预约到站”只用于带出与排队；它不是合同、不占额度、不产生开票、不进五流。
3. 到站场景最容易原生形成车货照片、磅单、地点、收购合同、付款等五流证据，也与现有“场站—收货员—收购单—结算单”模型一致。

**一期应支持的两个入口：**

- `WALK_IN + SITE_DELIVERY`：未预约直接到站；
- `SELLER_APPOINTMENT + SITE_DELIVERY`：预约到站，到场后带出预计品类、约量和车牌。

二者到场后必须汇入同一收购流程，不复制收购单、结算单或开票流程。

### 3.3 二期以后再评估的能力

| 能力 | 前置条件 | 为什么不建议一期做 |
|---|---|---|
| 上门回收 | 服务区域、人员车辆排班、路线、起收门槛、地址与到场留痕、移动计量 / 回场复秤规则 | 这是新的履约调度域，不是给预约加一个地址字段 |
| 企业大宗 | 单位出售者建模、正向开票 / 对公结算、合同与项目批次；若做竞价还需重议 ADR 0004 | 当前反向开票链路面向自然人；单位大宗不是同一税务流程 |
| 社区点 / 智能箱 | 普通居民轻量身份、设备接入、低额高频结算、清运工单、混投风控 | 与 ADR 0007 的专业出售者定位不同，单笔反向开票成本也不匹配 |
| 以旧换新 | 新品订单、补贴、品牌 / 零售渠道、安装与逆向物流联单 | 属于消费零售场景，超出现有“回收企业作业工具”边界 |
| 快递回收 | 在线估价、物流单、收寄验视、中心质检、改价 / 退回、数据清除 | 适合 3C 标准品，与当前大宗过磅模式不同 |

### 3.4 一个容易踩坑的命名问题

- 面向行业或政策材料：优先使用“**固定地点 / 固定站点回收**”“**回收交投点**”。
- 面向 youfeibao 现有领域模型：使用“**到站自送**”和“**预约到站**”；固定交易地点仍叫“**场站**”，不要同时引入门店、网点、仓库作为同义词。
- “客户预约”建议改为“**出售者预约**”。出售者不是平台客户，回收企业才是平台客户。
- 不把预约记录叫“预约单 / 订单”；沿用 ADR 0020 的“预约到站”。

## 4. 最终判断

**是，回收企业通常确实有上门回收和到站 / 到店自送，也常由客户先预约。** 但更准确的业务关系是：

```text
出售者发起：直接到场 / 预约 / 定时活动 / 周期计划 / 换新触发
                         ↓
物理交付：到站自送 / 上门取货 / 社区点 / 智能箱 / 流动点 / 物流寄送
                         ↓
现场事实：核验 → 称重或检测 → 定级扣杂 → 确认价格 → 交接
                         ↓
交易闭环：合同 / 协议 → 付款 → 开票 → 台账与运输凭证 → 分拣处理
```

对 youfeibao，一期不需要覆盖行业所有方式。应先把“专业出售者到站自送”做成证据完整的主链路，同时在数据上把交付方式、发起方式、服务时效分开，为将来的上门回收留口，但不提前引入调度、普通居民和撮合逻辑。
